# New site — "Ink & Cobalt"

A zero-dependency five-page static site: five sibling HTML pages sharing one
`styles.css`, plus a few lines of vanilla JS inlined in each page. No build step,
no external fonts, no frameworks, no network requests. Light and dark themes
follow the visitor's OS setting and can be overridden with the toggle in the nav
(the choice is remembered in `localStorage`).

```
index.html         Home — name, short intro, research interests, contact
research.html      Six projects, split into Active and Completed
publications.html  Five papers, split into Under review and In progress
talks.html         Three conference talks and one poster
teaching.html      Nine courses by campus, plus grants and service
styles.css         Shared design tokens and all layout
```

The home page is deliberately bare: everything else is one click away in the nav.

## Deploy (replace the old Jekyll template)

From the repo root:

```bash
# 1. Remove the academicpages template (everything stays recoverable in git history)
git rm -r _config.yml _config_docker.yml _data _includes _layouts _pages \
  _publications _research-projects _sass _talks _teaching assets markdown_generator \
  scripts talkmap talkmap.ipynb talkmap.py talkmap_out.ipynb \
  Gemfile Dockerfile docker-compose.yaml CONTRIBUTING.md package.json

# 2. Promote the whole page set to the root — all six files, not just index.html
git mv redesign/index.html redesign/research.html redesign/publications.html \
  redesign/talks.html redesign/teaching.html redesign/styles.css .
git rm redesign/README.md

# 3. Tell GitHub Pages to serve the files as-is instead of running Jekyll
touch .nojekyll && git add .nojekyll

# 4. Keep: CNAME, files/ (CV + slides), LICENSE. images/ is now unused.
git commit -m "Replace template with the Ink & Cobalt site"
git push
```

The pages link `files/CV_0408.pdf` and `files/2025_ssc_presentation.pdf` with
relative paths, so `files/` must sit alongside the HTML at the repo root — which
is where it already is. Until step 2 runs, the pages live one directory down and
those links will 404 in local preview; `redesign/files/` holds preview copies of
the two PDFs and is gitignored.

Every page declares `<link rel="canonical" href="https://hanlongchen.com/…">`
pointing at the root, so `redesign/` is listed under `exclude:` in `_config.yml`
to keep the staging copy from being published with root canonicals.

## Editing content

- **The intro** — the single `<p class="bio">` in `index.html`. The research
  interests below it are one line in `<p class="interests">`.
- **A paper** — copy one `<li>…</li>` into the right `<ol class="papers-list">`
  (Under review or In progress). The 01/02/03 numbering is generated by CSS and
  restarts per section, so nothing needs renumbering by hand. Equal-contribution
  and corresponding-author marks use `<span class="mark">&lowast;</span>`.
- **A project** — copy an `<article class="project">` block into the Active or
  Completed section of `research.html`; completed entries carry
  `class="project project--done"`.
- **A new CV** — overwrite `files/Hanlong_Chen_CV.pdf` and nothing else changes;
  all eleven links already point at that filename. Also re-check the counts in
  the eyebrows (`<span class="idx">05</span>papers` and friends) against it.
- **A photo** — there is no photo slot by design; the site is text-first. Ask
  Claude to add a portrait to the hero if you later want one.

Two things are duplicated on purpose and must be edited on all five pages or
none: the `<script>` block at the bottom, and the small theme script in `<head>`
(it has to run before the stylesheet loads, otherwise the page flashes the wrong
theme).

## Design tokens

Colours, fonts, spacing, and the container width are CSS custom properties in
the four `:root` blocks at the top of `styles.css` — light, OS-dark,
forced-dark, forced-light. Change a token once and it applies everywhere in both
themes. The accent (`--accent`, cobalt) is deliberately used in only a few
places: the paper numerals, the eyebrow numerals, links, the monogram dot, and
focus rings.
